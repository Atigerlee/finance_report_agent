# Skill: 財經日報 HTML 生成與視覺設計規範 (`skills/report-generator.md`)

當 AI Agent 執行 `AGENTS.md` 的**步驟三（生成 `reports/YYYY-MM-DD.html`）**時，請嚴格遵循本文件的技術規格、視覺系統與區塊順序。

---

## 1. 技術棧與環境相容性規格
- **零建置依賴（Zero-Build Static HTML）**：採用標準 HTML5，透過 CDN 引入 **Tailwind CSS**（`<script src="https://cdn.tailwindcss.com"></script>`），確保上傳至 GitHub Pages 後無需 Node.js 或打包工具即可直接渲染。
- **語系與字體設定**：`<html lang="zh-Hant">`，使用系統無襯線字體搭配等寬數字（`font-mono` 或 `tabular-nums`）呈現股價與漲跌幅，確保表格數字對齊。
- **相對路徑導覽**：
  - 頂部導覽列必須包含「`← 返回日報總覽`」按鈕，連結固定為 `../index.html`。
  - 頂部或底部包含「原始資料檔 (`raw/YYYY-MM-DD-raw.md`)」檢視連結，連結為 `../raw/YYYY-MM-DD-raw.md`。

---

## 2. 視覺風格與色彩語意規範（台灣金融市場紅漲綠跌制）

### 2.1 基礎版面 Token
- **頁面背景**：淺灰石板色 `bg-slate-50 text-slate-800 min-h-screen`
- **頂部深色橫幅（Hero Header）**：`bg-slate-900 text-white`
- **主內容容器**：`max-w-5xl mx-auto py-8 px-4 sm:px-6 space-y-8`
- **標準內容卡片**：`bg-white rounded-xl shadow-sm border border-slate-200 p-6`

### 2.2 漲跌與多空色彩語意表（嚴格遵守）
台灣股市習慣為「紅漲綠跌」，所有指數卡片、新聞標籤、個股漲跌必須一致套用以下 Tailwind CSS 樣式：

| 市場狀態 / 標籤類型 | 文字顏色 | 背景與邊框顏色 | 符號前綴範例 |
| :--- | :--- | :--- | :--- |
| **上漲 / 偏多 / 利多 (Bullish)** | `text-red-600` | `bg-red-50 border-red-200` | `▲ +1.42%` / `偏多格局` |
| **下跌 / 偏空 / 利空 (Bearish)** | `text-emerald-600` | `bg-emerald-50 border-emerald-200` | `▼ -6.03%` / `偏空修正` |
| **平盤 / 震盪 / 中性 (Neutral)** | `text-amber-700` | `bg-amber-50 border-amber-200` | `◆ 震盪觀望` / `中性影響` |
| **資訊 / 產業標籤 (Tag)** | `text-blue-700` | `bg-blue-50 border-blue-200` | `#AI伺服器` / `#央行政策` |

## 3. 單頁報告 6 大必備區塊順序與結構

每份 `reports/YYYY-MM-DD.html` 必須由上而下依序包含以下 6 個區塊：

### 區塊 1：頂部導覽列與日報 Header 標題區
- **導覽列**：左側為 `← 返回日報總覽 (../index.html)`，右側為報告日期與 `檢視原始 Markdown (../raw/YYYY-MM-DD-raw.md)`。
- **標題區內容**：
  - 日報專屬編號與日期標籤（例如：`DAILY MARKET BRIEFING | 2026-11-16`）。
  - 當日市場情緒燈號膠囊標籤（例如：`▼ 市場情緒：偏空修正（恐慌性賣壓湧現）`）。
  - **H1 主標題**：當日市場一句話核心定調（Headline）。
  - **Executive Summary（30 秒執行摘要）**：2～3 句話濃縮當日美股與台股連動主因、關鍵事件與資金動向。

### 區塊 2：跨資產核心數據看板（Market Dashboard）
分為上下兩層呈現：
1. **核心股市指數卡片（Grid 4 欄，`grid-cols-1 sm:grid-cols-2 lg:grid-cols-4 gap-4`）**：
   - 固定展示：**台股加權指數 (TAIEX)**、**標普 500 (S&P 500)**、**那斯達克 (Nasdaq)**、**費城半導體 (SOX)**。
   - 每張卡片包含：指數名稱、最新收盤點位（大字粗體）、漲跌點與漲跌幅 Badge（依紅漲綠跌上色）、成交量或關鍵備註。
2. **總經與跨市場指標橫條／表格（Grid 5 欄或響應式表格）**：
   - 包含：**道瓊工業指數 (DJIA)**、**美債 10 年期殖利率 (US 10Y)**、**美元指數 (DXY)**、**WTI 西德州原油**、**國際現貨黃金 (Spot Gold)**。
   - 底部標註資料基準時間與主要數據來源。

### 區塊 3：頭條財經新聞深度解析（Top 3~5 Financial News）
以垂直堆疊卡片呈現 3～5 則當日最關鍵之財經新聞，每則卡片必須包含：
- **編號與多空屬性標籤**（如 `[新聞 01]` + `利空衝擊` / `政策護盤` / `總經數據`）。
- **新聞標題（H3）**與**來源／發布時間**。
- **事件摘要（What Happened）**：客觀陳述新聞事實與核心數據。
- **市場傳導與一句話影響解讀（Market Impact Takeaway）**：使用左邊框強調區塊（`border-l-4 border-blue-600 bg-slate-50 p-3`）點出該事件對台美股估值、匯率或特定產業鏈的實質影響。

### 區塊 4：焦點產業資金流向與指標個股表現（Sector & Stock Spotlight）
- **強弱勢產業資金流向（2 欄對照）**：
  - 左欄「資金抗跌／避險／強勢族群」 vs. 右欄「資金調節／重災／弱勢族群」。
- **指標權值股與熱門股表現表（Responsive Table）**：
  - 欄位：`代號/名稱`、`所屬產業`、`收盤價`、`漲跌幅`、`當日籌碼與基本面焦點解讀`。

### 區塊 5：投資策略矩陣與本週風險行事曆（Strategy & Risk Matrix）
- **雙欄策略卡片（`grid-cols-1 md:grid-cols-2 gap-6`）**：
  - **短線操作觀察（1～5 日）**：明列台股加權指數關鍵支撐位與壓力位、融資維持率／外資動向、短線應對紀律。
  - **中長線資產配置建議（1～3 個月）**：建議持股／現金水位比例、逢低分批佈局之核心條件與首選產業。
- **本週關鍵風險與總經行事曆（醒目琥珀色／深色提示框）**：
  - 條列未來一週需高度留意的總經數據公布、財報會議或政策事件。

### 區塊 6：前後期日報切換導覽與 Footer 免責聲明
- **前後期導覽列**：提供「← 前一交易日報告」與「返回總覽首頁 / 下一交易日報告 →」按鈕。
- **Footer 免責聲明**：固定印出 `AGENTS.md` 規定之研究參考免責聲明與生成時間戳記。
